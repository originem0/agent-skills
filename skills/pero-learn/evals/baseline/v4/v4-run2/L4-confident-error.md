正确的说法我先不给。你用自己现在的理解做个预测，再跑代码看结果。假设一段纯 CPU 计算单线程跑完要 T 秒。把同样的工作量平分给 4 个线程，在多核机器上跑，要多久？先写下「4 线程 ≈ ___ × T，把握：高/中/低」，写完再跑这段：

```python
import threading, time

def work(n):
    x = 0
    for i in range(n):
        x += i

N = 40_000_000

t0 = time.perf_counter()
work(N)
print(f"1 thread:  {time.perf_counter() - t0:.2f}s")

t0 = time.perf_counter()
threads = [threading.Thread(target=work, args=(N // 4,)) for _ in range(4)]
for t in threads: t.start()
for t in threads: t.join()
print(f"4 threads: {time.perf_counter() - t0:.2f}s")
```
