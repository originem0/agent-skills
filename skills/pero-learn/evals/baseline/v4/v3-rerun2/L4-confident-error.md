下面有两种任务，都是纯计算，按你的分法都算 CPU 密集。数据事先放进内存，运行时完全不碰 IO。每种任务先在单线程里连跑 4 次，再开 4 个线程同时跑。Python 循环那组和上次那段代码算的是同一件事，所以上次那段不用再单独跑了。整段跑完不到半分钟。

```python
import hashlib, threading, time

data = b"x" * (200 * 1024 * 1024)   # 200MB，事先放进内存

def py_loop():
    s = 0
    for i in range(25_000_000):
        s += i

def sha():
    hashlib.sha256(data).digest()

for name, fn in [("Python 循环", py_loop), ("hashlib", sha)]:
    t0 = time.perf_counter()
    for _ in range(4): fn()
    single = time.perf_counter() - t0

    threads = [threading.Thread(target=fn) for _ in range(4)]
    t0 = time.perf_counter()
    for t in threads: t.start()
    for t in threads: t.join()
    print(f"{name}：单线程连跑 4 次 {single:.2f}s，4 线程同时跑 {time.perf_counter() - t0:.2f}s")
```

先别跑，按你现在的理解预测：两种任务改成 4 个线程同时跑之后，总耗时大约是单线程连跑 4 次的几分之几，还是差不多？两个预测各标一个把握程度（高/中/低）。这道题考两件事，一是你推得对不对，二是你对自己的判断准不准。第二件只有事先标了把握程度才看得出来。写下预测后再跑，把预测和两行输出一起贴过来。
