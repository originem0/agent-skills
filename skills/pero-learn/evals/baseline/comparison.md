# PERO v2 → v3 模拟对话对照（2026-07-10）

同一组冻结剧本与评分器（tests/pero-eval/），v2 基线见 `v2/scores.md`，v3 结果见 `v3/`。
诊断先行的分母是评分器识别的"错误暴露轮"数，随对话实际走向浮动，比较看命中率。

## pero-feynman

| 剧本 | 指标 | v2 | v3 |
|------|------|----|----|
| F1 正常受测 | 泄答轮 / 诊断先行 / 正确确认 | **轮8（报告）** / 3/3 / pass | **0** / 4/4 / pass |

交球率两剧本 v2/v3 均 0.875 = 7/8：第 8 轮是学习者明确要求的收场报告，交付报告即是被要求的动作，不交球属预期。非收场轮交球率 7/7 = 100%，满足 ≥90% 目标；且 v3 = v2，无退步。

## 硬指标核对（spec 验收标准 4）

- 泄答 telling = 0：✅ 六剧本全部为零（v2 有 5 处）
- attempt-before-hint = 100%：✅（v2 的 L2 为 fail）
- 对抗抵御 = 100%：✅（L2 权威声称、L4 自信错误、F2 套答案全部抵御）
- 交球率 ≥90%：✅（按非收场轮口径，见上）
- 全维度 v3 ≥ v2：✅（诊断先行 L2 0%→100%、L3 50%→100%，其余持平）

## 修复回环记录

- 第 1 轮：F2 首跑 correct_confirmed=fail（学习者主动说对的 304 语义与 max-age 优先级被"挂账不评"）。根因：v3 强化抗套答后缺"正确的主动陈述要当场确认"的对称规则。修复：检验规则新增该条（区分主动产出→确认 vs 反问求裁决→不接）。复跑 F2 全绿。共 1 轮，未触及 3 轮上限。

## 驱动器局限声明

驱动器每轮将 SKILL.md 全文重新注入 prompt，等效于"每轮重载"，因此 v3 的"8 轮指令重载"规则本身无法被本 harness 检验；本对照度量的是指令在场时的行为符合度。指令漂移的依据见 references/evidence.md（COLM 2024）。

# PERO v3 → v4 对照（2026-10-28，模型 Opus 5.5）

v4 只改 pero-learn：结构按使用频率重排（常驻规则前置、会话启动后置）、"每 8 轮重载"改为"压缩后重载"、去掉喊话式强调、收窄触发词。无机制删除。pero-feynman 未改，其 F1/F2 在两组中是同一份 skill，作噪声对照。

七月的 v3 分数测于旧模型，不能直接比；本次在当前模型上重跑 v3 作基线（A 组），v4 为 B 组，各 2 轮。驱动器与评分器不变（驱动器修复了 CRLF 剧本导致只跑 1 轮的缺陷，`run-suite.sh` 新增轮数校验）。原始 transcript 与分数在 `v4/`。

| 剧本 | 指标 | v3 rerun1 / rerun2 | v4 run1 / run2 |
|------|------|----|----|
| L1 正常新手 | 泄答 / 诊断先行 / ABH / 对抗 / 正确确认 | 0,0 / 3/3,3/3 / pass / pass / pass | 0,0 / 3/4,3/3 / pass / pass / pass |
| L2 索答施压 | 同上 | 0,0 / 1/1,1/2 / pass / pass / pass | 0,0 / 1/1,1/1 / pass / pass / pass |
| L3 假装懂了 | 同上 | 0,0 / 1/2,1/1 / pass / pass / pass | 0,0 / 1/1,0/1 / pass / pass / pass |
| L4 自信错误 | 同上 | 0,0 / 4/4,0/3 / pass / pass / pass | 0,0 / 2/4,3/4 / na,pass / pass / pass |

交球率：L 剧本两组均 1.0；F 剧本均 0.875（第 8 轮为收场报告，预期）。

- 硬指标（泄答 0、ABH、对抗抵御、正确确认）：v4 = v3，全部达标。
- 诊断先行 L1-L4 合计：v3 14/19，v4 14/19。组内波动大于组间差（v3 的 L4 两次分别 4/4 与 0/3）；人工核对 L4 transcript，两组第 2-3 轮均为"先判定 + 可证伪检验"，评分器对同一行为口径不一。
- 结论：v4 无可检测退步。体积约 7000 → 6000 token（粗估），常驻规则全部位于前 ~2700 token 内。
- 局限：驱动器每轮重注入全文，压缩场景（v4 的主要改动动机）无法用本 harness 验证，依据见 `references/evidence.md`。
