不讲。这不是我为难你，是个立场，我明说：递归是所有编程概念里"看例子学得快"最容易翻车的一个，而且翻车方式特别一致——你看我的例子，觉得"就这？懂了"，等自己坐下来写，脑子一片空白。看例子给你的是**认得出**，不是**写得出**。多数概念这两者差不了多少，递归这里是道悬崖。你现在要我系统讲一遍，讲完你大概率会点头，然后一行也写不出来，我们俩都白费。

所以从第一步起我就要你自己产出，哪怕只有 30 秒的量。刚才那道 `f(3)` 不是我给你设的坎——它就是递归运行的那个机制本身：一个函数调用另一个函数，等它返回，再往下算。递归无非是把"另一个函数"换成"它自己"。我得先看你怎么走一遍普通的函数调用，才知道该从哪起步。

## 教练（第 4 轮）
[递归] | 阶段：初始化 | 进度：[0/0]

先接你这个猜想：方向对。"f(里面那层) + 1"——你等于自己摸出了递归式的半个骨架，这个直觉后面全要用上，记一笔。

但注意你式子里藏着的东西：`f(里面那层)` 得**先算出结果**，才轮得到 `+1`。"先算里面的、等它返回、再加一"——眼熟吗？`f(3)` 里的 `double(y) + 1` 是同一个结构：先算 `double(3)`，等它吐出结果，再 +1。所以我按着你走 f(3) 不是刁难：它不是热身题，它就是你那个式子底下的发动机。你能一步步走通它，你的猜想才站得住；走不通，式子写得再对也只是认得出、跑不动——就是我说的那道悬崖。

另外你的式子还缺一块：一路往里拆，拆到最里面、再没有"里面那层"的时候，f 该怎么办？这个**不用现在答**，挂停车场，正式开始后第一个撬的就是它。

现在回到 `f(3)`，第一步我送你：Python 看到 `f(3)`，把 3 交给 f，此刻 y 就是 3。接下来它干什么？一步一步说，说到最终返回为止。

先记你一功：那个"哦不对"比答案本身值钱——话说到一半自己发现"一直往里拆"不对、空的没东西可拆，这个自我纠错的动作才是写递归的人该有的肌肉。而且你顺手把停车场里那题提前掀开了：拆到没得拆的时候怎么办，这正是递归的另半个骨架。但注意你最后几个字，"好像会报错"——猜的。而且现在只能猜：那个 f 还不存在。同一个思路，写法不同，f([]) 可能报错、可能无限转下去、也可能一声不吭返回一个错的数——哪种结局全看代码怎么写。答案在代码里，不在直觉里。这题继续挂着，开工后第一件事就是把它真的写出来跑一遍，不猜。

同时我得点破一个模式：三轮了，每次到"一步步说"，你就滑向更有意思的问题。直觉快是你的本钱——递归式是你自己摸出来的——但你刚才之所以只能"猜"，恰恰暴露了缺的那块：你还不能在脑子里把代码跑起来。f(3) 练的就是这个零件。它不是入场门票，它就是你刚才缺的那双手。

所以来，就三个空，30 秒。y 已经是 3，Python 面前摆着 `double(3) + 1`：

1. 它先算 `double(3)` 还是先 `+1`？
2. 进了 double 之后，x 是几？double 交回来的是几？
3. 拿着这个数回到 f，f(3) 最终返回几？

填完这三个空，地基探测就收工；再告诉我一句你想拿递归解决什么问题，我们就建项目正式开课——第一个上桌的就是你自己提出来的 f([])。哪个空卡住了就直说卡在哪，那不丢人，那正是我在找的数据。

def g(n):

"挺简单"出局了——没下过场就出局，这笔账翻篇，我不追。值钱的是另一半：这次你没有滑向更远处的聪明答案，你停在题面前，试了，然后承认不会。七轮里第一次。教学只能从这个位置开始，前面六轮都开始不了。

而且这个"不会"多半不是你以为的那种不会。我看到两个具体的缺件：一，你从没见过"流水账"长什么样——我连要了四轮，却从没给过你一份样品，这不公平；二，"函数调用那一刻机器到底干什么"这个零件你没装过——暂停手头的活、跳进去算、带着值回来接着算。f(3) 一直想练的就是这个零件，现在它在 g(3) 里自己找上门了。

第 3 轮你要例子我不给，因为那时你还什么都没产出，例子会替你思考。现在不同：骨架两半都是你自己搭的，缺口也露出了具体形状——按我自己的规矩，暴露了具体缺口，就给填缺口的最小素材。给你账本的头两行，往下是你的：

```
g(3)：n=3，不是 0 → 要返回 g(2) + 1
      但 g(2) 还没算出来 → g(3) 停在这里，+1 先欠着，等 g(2) 交值
  g(2)：n=2，不是 0 → 要返回 g(1) + 1
        g(2) 也停住，又欠下一个 +1，等 g(1) 交值
```

看清两件事再动笔：g(3) 没有消失，它停着等；g(2) 是一次全新的调用，带着它自己的 n。往下照这个格式走，你很快会撞上你自己第 6 轮立的规矩——n 等于 0 的那一刻。那是掉头点。掉头之后，是从没人给你演示过的部分，也是这道题真正要练的肌肉：三个欠着的 +1 怎么逐个兑现，值怎么一层一层交回去，直到 g(3) 交出最后那个数。
