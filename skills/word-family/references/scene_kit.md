# 画面零件手册

目录：坐标 · 人物 fig · 箭头与标注 · 道具 · 基础图形 · 常用构图 · 自动检查 · 添加新零件

## 坐标

- 每个画面是 `viewBox 0 0 280 122` 的 SVG，地面是 `y=108` 的一条线（`{"items":[...], "ground": false}` 可去掉地面）。
- 人物 `fig` 的 `x` 是**双脚中点**，头心在脚上方 64，头顶在 y≈34（缩放 `s` 时按比例变）。站在地面上时不用写 `y`。
- 画面右边留出 16 的边距：内容放在 x ∈ [16, 264]，y ∈ [8, 120]。
- 两个人物之间至少隔 40，否则手臂会交叠。
- **所有零件都支持 `op`（透明度）**，用来画「原来的位置」残影。

## 人物 `fig`

```json
{ "k": "fig", "x": 92, "pose": "pull", "rope": [178, 82] }
```

| 参数 | 说明 |
|---|---|
| `pose` | 姿势，默认 `stand` |
| `flip` | `1` = 面朝左（默认面朝右） |
| `rope` | `[x, y]`：从手部画一根绳子到这一点，「拉」类画面必备 |
| `op` | 透明度。`0.3` 左右 = 灰色残影，表示「原来的位置」 |
| `s` | 缩放，0.7 = 远处或台阶上 |
| `y` | 脚踩的高度，默认 108 |

视频需要表达真实位移时，可在人物上加 `id` 与 `motion`：`{"k":"fig","id":"porter","x":80,"pose":"carry","flip":1,"motion":{"from":[204,108],"duration":3.2}}`。`x/y` 仍是终位，`from` 写实际起点；搬运的道具加 `"follow":"porter"`，与人物同行。站立背景和残影不自动移动。HTML 仍显示原有终位，动画只由视频读取。

不要把灰色人物一律当作起点，它也可能是队伍里的其他人。只在场景明确表达原位与新位时指定轨迹；同一场景的 id 唯一，follow 必须指向该场景的人物。搬运时对象与手的接触保持，支撑时可以只在原地屈膝用力。

**姿势**（面朝右时的样子）：

| pose | 样子 | 适合 |
|---|---|---|
| `stand` | 站立，手自然下垂 | 默认、旁观者 |
| `walk` | 迈步向右 | 离开、前往 |
| `pull` | 身体后仰，双手向右前方拉绳 | 拉、拖（tract, duct 引导） |
| `push` | 前倾，双手向右推 | 推、压（press, pel） |
| `give` | 右手平伸递出 | 给、递、放（don, mit, pose） |
| `point` | 右手斜上指 | 指、说、喊（dict, claim） |
| `explain` | 右手抬起摊开 | 辩解、说明 |
| `withdraw` | 右手收回胸前 | 收回、克制 |
| `think` | 右手扶额 | 想、忘、记 |
| `stern` | 双手叉腰 | 命令、禁止 |
| `carry` | 双手举过头顶 | 扛、支撑（port, sist 在下面撑） |
| `lean` | 上身后仰躲闪 | 避开、偏开 |
| `sit` | 坐（没有椅子，需要自己配一个 rect） | 坐（sed, sess） |

## 箭头与标注

| 零件 | 例子 | 说明 |
|---|---|---|
| `arrow` | `{"k":"arrow","pts":[[186,48],[134,48]],"dash":1}` | 折线箭头；`curve:1` 且 3 个点时为二次曲线；`d` 可直接给 SVG path（如圆弧掉头）；`c` 改颜色（默认赭石） |
| `line` | `{"k":"line","x1":118,"y1":14,"x2":118,"y2":112,"dash":1}` | 分隔线，常用来把一个画面分成左右两格 |
| `text` | `{"k":"text","x":56,"y":82,"text":"do","size":34,"serif":1}` | 文字；`c` 颜色，`op` 透明度，`rot` 旋转，`anchor` 对齐 |
| `tag` | `{"k":"tag","x":140,"y":66,"text":"注意力","tone":"root"}` | 圆角标签；`tone`：`pre`（赭石）/ `root`（墨绿）/ `muted`（灰）/ 默认蓝 |
| `bubble` | `{"k":"bubble","x":100,"y":18,"text":"不了，我戒了","tail":[86,38]}` | 对话气泡；`tail` 指向说话人嘴边 |
| `thought` | `{"k":"thought","x":118,"y":22,"text":"？","from":[84,40]}` | 想法泡泡，`from` 是头部位置 |

## 基础图形（零件库里没有现成道具时用）

```json
{ "k": "rect", "x": 40, "y": 80, "w": 30, "h": 28, "r": 3 }
{ "k": "circle", "x": 60, "y": 70, "r": 10 }
{ "k": "path", "d": "M20,108 Q60,60 100,108", "c": "#176b4d" }
```

可选参数：`fill`（默认米色）、`c`（线色）、`sw`（线宽）、`op`。

## 常用构图

- **离开 / 移动**：原位放 `op: 0.3` 的残影，新位置放实体，中间一条 `dash` 虚线箭头。
- **拉**：`pull` 姿势 + `rope` 连到物体，物体上方加一条指向人的虚线箭头。
- **挂、吊、提着**：任意有手部挂点的姿势（`point`、`give`、`carry`）+ `rope` 垂直连到下方的物体，物体用 `circle`/`rect`/`crate` 表示。
- **一词多义**：用 `line` 把画面分成左右两格，每格一个义项，`caption` 写「左：……右：……」。
- **对比方向**：两个人分别从两侧拉（一个 `flip: 1`），箭头向外。

## 自动检查

`scripts/build.py` 生成页面后会在浏览器里实测每个零件的位置：文字压文字、文字被人物遮住超过三分之一、零件超出画面、家族图文字重叠，都会以 `[提醒] 版面 …第 N 个零件…` 报出来。按编号找到 scene 数组里对应的零件（从 1 数起），挪坐标后重新生成。

## 添加新零件

当一个新词根需要的动作或物件反复出现时（例如「坐」需要椅子），再往共享的 `assets/kit.js` 里加：

- **新姿势**：在 `POSES` 里加一项，只写和 `BASE` 不同的部分。坐标以双脚中点为原点、面朝右，`hand` 是绳子的挂点。
- **新道具**：在 `K` 里加一个函数 `name: o => \`<g ...>...</g>\``，沿用现有配色常量（`INK`、`PRE`、`ROOT`、`FILL`、`PINK`），线宽 1.6–2.0。

`build.py` 会自动从 kit.js 读取零件名和姿势名，不需要另外登记。改完运行 `python scripts/build.py --all`，确认旧课程不受影响。HTML 用静态姿势表达关系；视频在共享场景上增加人物关节动作和镜头，不把整张图的缩放当成人物动作。
