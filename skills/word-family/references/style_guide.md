# 教学风格规则

来源：对 B 站「RYAN的英语笔记」22 条视频的口播转写和板书逐帧分析（原始材料在 `ryan_analysis/`），以及使用者在试做过程中的三次纠偏。

## 一、核心结构：一个点 → 一个面

一课只讲**一个**词根或词缀家族，并且必须从**一个日常锚点**出发：

1. **日常锚点**：学习者天天见、早就认识的词或场景，例如拖拉机 tractor、机场 airport、行李提取牌 Baggage Claim、摆 pose、按 press 键。最好的锚点有两种：
   - 中文名本身就泄露了词根义（拖拉机 = 拖 + 拉 → tract）；
   - 两个熟词之间有表面矛盾（为什么 visit 是拜访，visa 却是签证？为什么 contract 既是合同又是收缩？）。
2. **母画面**：词根的核心义要落成**一个具体动作**，一个人能做出来、画得出来的动作：拉、站、看、压、喊、扔、跑、放。不能写成「表示……的概念」这类抽象释义。
3. **同一画面换方向**：家族里的每个词都是**同一个人在做同一个动作**，只是前缀换了方向——往自己拉、往两边拉、往外拉、往一起拉、从底下拉、往回拉。卡片之间的连结就来自这里。
4. **回扣锚点**：结尾用一个意想不到的日常词收回开头（拖拉机拖一个车斗 → 拖一长串就是火车 train）。
5. **收成一个面**：家族图把所有词摆回同一个词根周围。

**禁止硬凑。** 用户一次给了几个互不相干的词根/词缀（例如 ab-、de-、apo-、for-），不能合进一课。要么拆成几课，要么挑一个当锚点，并且**先告诉用户为什么**。一课里出现两个以上互不相关的母画面，就说明凑了。

**词根本身多义时**（拉丁语 pendere 既是「挂」又是「称」）：选更具体、更日常的那个义当母画面；另一个义只有在**能从母画面一步画出来**时才收进同一课（「挂」→「挂上秤」→「称」），并且要用一张过渡卡把这一步明确讲出来、在 caveat 里交代演变关系。一步画不出来，就把另一个义拆成下一课。结尾回扣词可以来自第二个义的分支，但要在过渡句里回到开头的锚点画面。

## 二、每张卡片怎么写

| 字段 | 要求 | 反例 |
|---|---|---|
| link（过渡句） | 承接上一张卡的方向变化：「如果不是往一个方向拉，而是两股力往两边拉呢？」 | 「下面看 distract。」 |
| literal（字面画面） | 具体到谁、往哪、对什么：「把注意力往不同方向拉开」 | 「分离的拉」 |
| bridge（桥接） | 先摆画面，再用反问把画面接到词义：「……这不就是分心吗？」让读者自己完成最后一步推理 | 直接写「意为分心」 |
| meaning | 词性 + 常用义，按常用度排序 | 罗列十个冷僻义项 |
| senses | 派生词、一词多义、真实搭配。一词多义用**条件分叉**：「如果拉到一起的是东西，就是收缩；如果是两个人，就是合同」 | 只列义项不解释 |
| 语境固化 | 词义为什么偏偏落在这里：「常用在医学语境里，慢慢固定成注射」「1590 年代起才有染病义」 | — |
| ex | 一句自然、日常、能直接用的英文例句 + 中文 | 教科书腔长句 |
| caveat | 变体（ad- 碰到 t 同化成 at-）、联想标注、近义辨析。**最多两句话**，细节放进 fact 或删掉 | 一段六行的考据 |
| fact | 一行可追溯的词源事实：拉丁/希腊原形 + 构成 + 关键年代 | — |

## 三、诚实规则（硬性）

1. **词源只来自 `scripts/etym.py` 的查询结果**，不凭记忆。查不到就换词形再查；仍查不到，就不用这个词，或者明确标「词源存疑」。
2. **联想和词源分开标。** 为了好记而用的画面如果没有史料支持，必须在 caveat 里写明「这是联想」。例：forget 的「松手」画面是联想，有记载的是 "un-get"。
3. **形近不等于同源。** track 和 tract 长得像、意思也沾边，但 track 词源存疑、一般认为来自日耳曼语；river 和 derive 里的 rivus 也不同源。这类词放进「形近陷阱」，正好帮学习者避坑。
4. **etymonline 的「Entries linking to」只是候选清单**，里面混着只是顺带提到该词的词条（tract 的清单里有 meadow、oasis）。每个候选都要单独查证构成。
5. **变体如实标注**：同化（ad- → at-/as-/ac-，ex- → e-/ef-，sub- → sup-/suc-，in- → im-/il-/ir-）、元音交替（cap/cip/cept）。不许悄悄变形。具体做法见下一节。

## 三点五、变体与同化（必做）

很多词根词缀不止一个样子。学习者不知道变体，就认不出 illegal、impossible、irregular 其实都是 in-，也看不出 attract、accept、assist 都是 ad-。所以：

1. **先查清有哪些变体。** etymonline 的词条会写「assimilated form of ad-」「variant of」「past participle stem」之类，查到就记下来。不凭印象编变体。
2. **两类变体分开写：**
   - **这一课的词根/前缀本身的变体** → 写进 `root.variants`，每项写形式、出现条件、一个例词：
     `{"m": "im-", "note": "b、m、p 前", "ex": "impossible"}`、`{"m": "pens", "note": "过去分词词干", "ex": "dispense"}`。
     页面会在母画面区和家族图中心显示。
   - **某个主词里出现的其他前缀的同化形式**（tract 课里 attract 的 at-）→ 在这个词素上写 `"of": "ad-"`，标签会自动显示「ad- 的同化形式」；不是同化而是缩略的（spend 的 s- 来自 ex-），加 `"how": "缩略"`。
3. **主词要覆盖常用变体。** 课程本身就是一个有变体的词根或前缀时（in-、ad-、con-、cap/cip/cept），主词至少覆盖其中两个最常用的变体，而不是只讲基本形。
4. **讲清为什么变**，一句话就够，写在第一次出现变体的那张卡的 caveat 里：
   - 同化：前缀的最后一个辅音向后一个辅音靠拢，为了顺口。「in- 碰到 l，n 和 l 连读别扭，干脆也变成 l：in + legal → illegal。」
   - 元音交替/词干变化：拉丁语动词不同时态的词干不同（capere → captus → -cipere）。
5. **变体不改变意思。** 画面上要让读者看出：换了个样子，还是同一个动作、同一个方向。

`scripts/build.py` 内置了常见同化表（ad-、com-/con-、in-、ex-、sub-、ob-、dis-、syn-、ab-）：主词里出现 at-、im-、sus- 这类形式却没写 `of`，或者课程本身是 in- 却没列 `root.variants`，都会提醒。提醒可能误报（例如希腊语的 an- 表否定，不是 ad-），误报就在交付时说明理由。

## 四、选词

- 主词 5–7 个，按「方向」铺开，每个前缀方向只出现一次，尽量让方向两两成对（往外/往回，往一起/往两边）。
- 优先高频、实用、阅读中真会碰到的词；冷僻词只放进迁移题。
- 每课准备：1 个结尾回扣词（日常、意外）、2–4 个形近陷阱或家族成员补充、3 道迁移题（同一母画面，读者自己推方向）。

## 五、语言

- 中文口语，短句，有停顿感。「其实就是」「你看」「这不就是……吗」都可以用——反问是推理工具，不是口癖。
- 术语精确时用（同化、元音交替、逆构词），不为了通俗而稀释。
- 不抄 Ryan 的原话、原例、原图，只学结构和手法。

## 六、视觉

- 静态线稿：细线火柴人、米白底、墨色线条，点缀色只用赭石（前缀、方向箭头）和墨绿（词根）。
- 不用 emoji，不做位移动画，不用高饱和色。
- 方向用「灰色残影 + 赭石虚线箭头」表达：原位放一个半透明的人或物，箭头指向新位置。
- 每个画面只讲一件事；画面说明（caption）一句话说清画的是什么。
