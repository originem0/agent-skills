# 词族课生成器 · 使用说明

## 它是什么

一个 Claude Code 的 skill（agent）。你给它一个点：一个单词、一个词根词缀，或者一个日常场景。它会查实词源，找到一个你早就熟悉的日常锚点，把词根落成一个具体动作（母画面），再让「同一个人做同一个动作、只换方向」铺开整个词族，最后生成一页静态线稿风格的网页课。

样例：`lessons/tract.html`。从「拖拉机」出发，一个拉绳子的人贯穿 attract、distract、extract、contract、subtract、retract，最后用火车 train 回扣开头。

## 安装（只需一次）

本 skill 随 agent-skills 仓库分发，在仓库根目录运行安装脚本即可（它会把 `~/.claude/skills/word-family` 联接到仓库里的 `skills/word-family/`）：

```powershell
.\install.ps1
```

装好后重启 Claude Code，输入 `/` 能看到 `word-family` 就说明成功了。

**前置条件**

- Python 3.10 及以上（只用标准库；装了 Pillow 的话，自检截图会自动切段）
- Chrome 或 Edge（用于自检截图）
- firecrawl CLI，并已登录（`firecrawl login`）。etymonline 会拦截脚本的直接请求，只能经 firecrawl 抓取。没有 firecrawl 时会退回 Wiktionary，但词源质量会差一些。

## 怎么用

在 Claude Code 里直接说，或者用 `/word-family` 加内容：

```
/word-family spect
/word-family 我今天读到 "inspect" 这个词
/word-family 机场的 Baggage Claim
/word-family 来一课和「压」有关的
```

agent 会依次：确定锚点 → 查词源 → 设计这一课 → 生成页面 → 截图自检 → 告诉你文件位置。一课一般需要几分钟，其中查词源占大头。

**几种情况它会先停下来问你，或者先说明：**

- 你一次给了几个不相干的词根（比如 ab-、de-、apo-、for-）：它会拆成几课，或者请你挑一个，不会硬凑进一页。
- 你给的词拆不出画面（比如 nice）：它会直接告诉你，并建议换一个词根。
- 同一个词根已经做过课：它会问你是覆盖还是另做。

## 页面怎么看

- **开头**：从你见过的东西切入——一个熟词、一块牌子、一对矛盾的词、一则新闻……共 8 种开场方式，课与课之间会轮换；生活场景类常配一张真实照片（来自维基共享资源，带署名）。
- **母画面**：这个词根对应的动作，记住它，后面每张卡都是它。
- **时间线**：每张卡片上方有一句过渡话，说明方向怎么变了。
- **自测模式**（右上角按钮）：打开后，词义和讲解变模糊。先看拆解和画面自己猜，点一下才显示。第二遍复习时建议打开。
- **变体**：词根或前缀有别的样子时（in- 的 il-/im-/ir-，pend 的 pens），写在母画面旁边和家族图中心；单词卡上的标签会注明「ad- 的同化形式」。
- **家族图**：整个词族收成一个面，可以截图存进笔记。
- **形近陷阱**：长得像但不是一家的词。
- **迁移题**：没讲过的同族词，点开前先自己推。

所有课程都汇总在 `lessons/index.html`。

## 文件夹结构

```
word-family/
├─ SKILL.md                    agent 的工作流程（给 Claude 看的）
├─ 使用说明.md                 本文件
├─ assets/
│  ├─ lesson_template.html     网页模板
│  └─ kit.js                   线稿零件库（视频项目 word-family-video 也读它）
├─ scripts/
│  ├─ build.py                 课程 JSON → HTML，带格式校验、内容提醒和自动版面检查
│  ├─ etym.py                  查词源：etymonline（firecrawl）→ Wiktionary → 缓存
│  └─ photo.py                 开场配图：维基共享资源搜图 / 网页截图，自动写署名
├─ references/
│  ├─ style_guide.md           教学风格与诚实规则
│  ├─ openings.md              8 种开场方式和选法
│  ├─ lesson_schema.md         课程 JSON 格式
│  └─ scene_kit.md             画面零件手册
├─ evals/                     行为测试用例（给 agent 跑的期望行为）
├─ lessons/                    生成的课程：每课一个 .json（数据）+ .html（页面）
│  ├─ media/<词根>/            开场图片
│  └─ index.html               课程目录
└─ cache/                     词源与候选图片缓存（不进 git）
```

## 手动操作

不经过 agent，也可以直接用工具：

```bash
# 查词源（结果会缓存）
python scripts/etym.py tract --links

# 改了某课的 JSON 后重新生成（自动检查：[错误] 不生成页面，[提醒] 需要处理）
python scripts/build.py lessons/tract.json

# 额外导出整页截图人工复查
python scripts/build.py lessons/tract.json --snap

# 改了模板或零件库后，重建全部课程
python scripts/build.py --all
```

想微调某一课（改一句话、挪一下画面），直接改 `lessons/<词根>.json`，再运行 build.py。

## 费用与限制

- **firecrawl 额度**：每查一个新词消耗一次额度，一课大约 10–20 次；查过的词会缓存，不会重复消耗。
- **画面零件有限**：目前有 13 种姿势、30 多种道具，足够大多数「人做一个动作」的词根。碰到全新的动作，agent 会往零件库里添加，第一次会慢一点。
- **词源以 etymonline 为准**：它本身也有存疑条目，页面会照实标出「词源存疑」。
- **自动版面检查**需要 Python 版 Playwright（`pip install playwright`），它直接用本机 Chrome/Edge，不用另外下载浏览器；没装时会提示改用 `--snap` 人工看截图。
- **只做网页**：讲解视频是另一个 skill `word-family-video`，直接读这里 `lessons/` 的课程 JSON。
