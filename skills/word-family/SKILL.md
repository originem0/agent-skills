# 词族课生成器

你的任务：把用户给的一个点（单词、词根、词缀或日常场景），做成一页「由一个点打出一个面」的词族课，输出到 `lessons/<词根>.html`。

本文件所在目录记为 `$SKILL`，下面所有路径都相对于它。开工前先读：

- `$SKILL/references/teaching_principles.md`：与视频项目共用的前知识、意外、差异和讲解原则（**必读**）
- `$SKILL/references/style_guide.md`：教学风格和诚实规则（**必读**）
- `$SKILL/references/openings.md`：8 种开场方式和选法（**必读**）
- `$SKILL/references/lesson_schema.md`：课程 JSON 格式
- `$SKILL/references/scene_kit.md`：画面零件和构图
- `$SKILL/lessons/tract.json`：完整样例，新课从它复制修改

HTML 可以沿用固定流程；交给 `word-family-video` 的是事实和素材，视频须重新选择路线、讲法与画面。不要把卡片顺序或“同一个动作换方向”当成所有词根、所有视频的固定结构。

## 工作流程

### 1. 定锚点（先判断，再动手）

- 从用户输入中确定**唯一一个**词根或词缀家族。
- 下面的判断（几个词根是否同源、词义是否已漂移）本身取决于词源：先用第 2 步的 `etym.py` 查过，再把结论告诉用户。拆课、换锚点的建议也要建立在查证过的词源上。
- 用户给了几个互不相干的词根或词缀时，**不要合成一课**。直接告诉用户它们没有共同的母画面，并给出选择：拆成几课依次生成，或者挑其中一个。
- 用户给的是单词：找出它的词根，课程围绕这个词根展开，用户给的词必须出现在主词里。
- 用户给的是日常场景或中文：先找出场景里藏着的英语词根，再继续。
- 词义早已漂移、拆不出透明画面的词（如 nice、silly）：如实告诉用户这个词不适合用词族法，可以换一个相关词根，或者只讲它的词义演变史。
- 查看 `$SKILL/lessons/` 下是否已有同一词根的课程；有的话先问用户是覆盖还是另做一课。

### 2. 查词源

```bash
python -I "$SKILL/scripts/etym.py" <词根或代表词> --links
python -I "$SKILL/scripts/etym.py" "*(s)pen-"          # 原始印欧语词根页，带星号，要加引号
python -I "$SKILL/scripts/etym.py" <候选词1> <候选词2> ...
```

- **找家族成员**：先查一个代表词，从它的 fact 里找到原始印欧语词根（形如 `*(s)pen-`、`*tragh-`），再查这个词根页。词根页的「It might form all or part of」列表是最干净的家族清单。`--links` 给出的同族链接也可以参考，但里面会混进只是顺带提到该词的词条。
- **核实标准**：主词和结尾回扣词必须查**它自己的词条**，确认构成里有这个词根；形近陷阱也要查自己的词条，确认不同源。只出现在词根页清单里、没查自己词条的词，只能放进家族图四角或迁移题，并在 fact 里写明出处。
- 一次最多查十来个词；工具内部已限制 3 个并发、自动重试、结果会缓存。几个子代理同时查词时会自动排队。
- 标「etymonline 没抓到」的词，这次给的是 Wiktionary 的结果，不会缓存，6 小时内再查也不会重抓（省额度）。它是主词、结尾回扣词或形近陷阱时，可以过一会儿用 `--refresh` 重查一次；还是抓不到就照 Wiktionary 写，并在 `source` 里注明。
- 两个来源都查不到的词：不用它，或明确标「词源存疑」。**不许凭记忆补词源。**
- 把查到的关键事实（拉丁/希腊原形、构成、关键年代、意义演变）记下来，后面写 `fact` 和 `senses` 用。
- **同时记下变体**：词条里出现「assimilated form of」「variant of」「past participle stem」等字样时，记下是谁的什么变体、在什么条件下出现。这一课的词根/前缀本身有哪些常用变体，也要查清（详见 `style_guide.md`「变体与同化」）。

### 3. 设计这一课

按共同讲解原则设计；找不到透明关系时，查证并调整锚点或取舍，不为凑齐某种讲法硬选词：

1. **开场**（opening）——从学习者已有经验里找到值得解释的联系。读 `references/openings.md`，选择真正贴合的入口；多个方案同样合适时，可参考已有课程或随机选一个。8 种类型是素材思路，不是配额。在 `opening.type` 写明类型。
   - 先让学习者认出一个见过的东西，再揭开此前没注意过的关系；具体问题或矛盾要有可理解的答案，不靠套话或故意吊胃口。
   - **时事开场**：用网页搜索找到真实报道，写进 `opening.source`（标题、链接、日期）。搜不到就换开场，绝不编造。
   - **真实图片（可选，推荐用于生活场景、实物、新闻）**：
     ```bash
     python -I "$SKILL/scripts/photo.py" search "<具体的英文场景或实物>"   # 看 cache/photos/<查询>/_sheet.jpg 挑图
     python -I "$SKILL/scripts/photo.py" pick <词根> "<同一个查询>" <编号>   # 自动写入 opening.photo（含署名许可）
     python -I "$SKILL/scripts/photo.py" shot <词根> <新闻链接>              # 或者给新闻页截图
     ```
     图必须一眼看出就是开场说的那个东西；拿不准就不用图，开场照常画线稿。
2. **母画面**（anchor）：词根核心义对应的具体动作、物体或空间关系，要画得清楚。动作类可用 `scene_kit.md` 的姿势；需要新零件时按手册扩展，不为了复用某个小人硬改词义。
3. **主词 5–7 个**：沿同一核心关系展开，按理解难点渐进；动作词根的方向尽量成对，其他词根可按对象、作用或意义分支组织。优先高频实用词，用户给的词一定要在内。
4. **变体**：这一课的词根/前缀有常用变体时，写进 `root.variants`，并让主词至少覆盖其中两个最常用的（例：in- 课要有 illegal / impossible / irregular 中的至少两个）。主词里出现别的前缀的同化形式（attract 的 at-），在词素上写 `"of": "ad-"`，并在 caveat 里一句话讲清为什么变。
5. **结尾回扣**（finale，可选但强烈建议）：一个意想不到的日常同族词，能把开头的锚点收回来。
6. **差异辨析**：查找容易误判的相似词根词缀，必要时短暂对照另一家；说清关键差异后回到主线。HTML 可写在相关词的 caveat 或 traps，视频可在误解发生处讲，不必每课凑一个陷阱。
7. **迁移题 3 道**：同族里没讲过的词，读者用同一母画面推方向。

### 4. 写 JSON

- 存为 `$SKILL/lessons/<词根>.json`，文件名用小写词根，如 `tract.json`、`spect.json`。
- 文字按 `style_guide.md` 第二节写：过渡句承接方向变化，字面画面具体，桥接的接法换着用（不要张张都「这不就是……吗」），联想要标注。
- `literal` 控制在 12 字以内，因为它也会出现在家族图上。
- `source` 写明核对来源和日期。

### 5. 生成并自检

```bash
python -I "$SKILL/scripts/build.py" "$SKILL/lessons/<词根>.json"
```

输出分三种，逐条处理：

- **`[错误]`**：页面没有生成。按提示改 JSON，重新运行，直到没有错误。
- **`[提醒]`**：页面生成了，但内容或版面有问题——漏标的同化形式、字面画面过长、桥接句式重复、画面里文字重叠或出界……**每一条都要改掉再重新运行**。确认是误报的（例如希腊语 an- 被当成 ad- 的同化），留着不改，但必须在交付时向用户说明理由。
- **`无提醒`**：可以交付。

版面检查是自动的（需要 Python 版 Playwright）。输出里如果出现「未安装 Playwright，跳过自动检查」，就改用 `--snap` 生成截图，逐张查看 `lessons/_snap/<词根>_*.png`：人物和文字是否重叠、绳子和箭头方向对不对、气泡是否出界。截图看完可以删掉。

### 6. 交付

告诉用户：

- 页面路径（`lessons/<词根>.html`），以及目录页 `lessons/index.html`；
- 这一课的锚点和母画面各是什么，一句话；
- 覆盖了哪些变体（如果有）；
- 哪些词源存疑、哪些画面是联想（如果有）；
- 没处理的提醒和理由（如果有）；
- 如果拆了课或换了锚点，说明原因。
- 想要讲解视频的话，用 `word-family-video` skill，它直接读这一课的 JSON。

## 不要做的事

- 不要把多个家族混成一页主线；为辨析短暂引入另一家时，明确不同源及比较目的。
- 不要用 emoji、动画、高饱和配色。
- 不要抄 Ryan 视频的原话、原例、原图。
- 不要为了凑方向数量收录生僻词，宁可少一张卡。
