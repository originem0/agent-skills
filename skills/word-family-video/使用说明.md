# 词族讲解视频 · 使用说明

## 它是什么

把 `word-family` 做好的词族课，变成一支 5 分钟以内的讲解视频。画面和网页版是同一套线稿：

- **线稿逐笔画出**：先画线、后上色；
- **按解说出场**：讲到哪一句，对应的标签、单词、释义才升起来；
- **版式轮换**：每换一个词，在「图右文左 / 图左文右 / 大字主角」之间切换，画面卡片带一点倾斜和阴影；
- **家族条和家族图**：底部一直显示这一家的进度，结尾的家族图按解说逐个点亮；
- **配音和字幕**：微软 edge-tts「云健」配音（免费，试听六个音色后选定，可用 `--voice` 换），字幕直接画在画面里。
- **开场**：沿用课程里的开场方式（熟词、生活场景、双词矛盾、时事……8 种，课与课之间轮换）；课程配了真实照片的，视频开场是一张「贴在纸上」的照片，镜头缓慢推近，署名一直显示。

样片（本地生成，不进 git）：`projects/tract/tract.mp4`（熟词拆名开场：从拖拉机讲到火车，4 分 17 秒）、`projects/pend/pend.mp4`（双词矛盾开场：depend 依靠 vs spend 花钱，4 分 40 秒，超时自动删掉了形近陷阱）。两课的解说词 `narration.json` 在仓库里，可以照着写。

## 安装

和 word-family 一样，在 agent-skills 仓库里运行安装脚本（或手动建联接）：

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\.claude\skills\word-family-video" -Target "D:\Development\Automation\agent-skills\skills\word-family-video"
```

依赖：

```bash
pip install edge-tts numpy playwright      # Playwright 直接用本机 Chrome/Edge，不用另下浏览器
pip install pillow faster-whisper          # 可选：定格总览图、读音检查（首次检查会下载 large-v3-turbo，约 1.6GB）
```

另需 ffmpeg 在 PATH 里，以及同目录下的 word-family skill。

## 怎么用

在 Claude Code 里：

```
/word-family-video tract
/word-family-video 把 pend 那一课做成视频
```

agent 会：生成解说词草稿 → 改写成口语 → 量时长（超时自动删减）→ 出定格图检查画面 → 渲染 → 读音检查 → 告诉你结果。

## 手动操作

```bash
python scripts/video.py init   tract   # 解说词草稿 → projects/tract/narration.json
python scripts/video.py plan   tract   # 配音、量时长、自动删减，打印每个单元
python scripts/video.py stills tract   # 每个单元一张定格图 → projects/tract/stills/
python scripts/video.py render tract   # 成片 → projects/tract/tract.mp4
python scripts/video.py check  tract   # 读音检查
```

想改某句话：直接改 `projects/<词根>/narration.json`，再 `render`。只有改过的句子会重新配音。
写法见 `references/narration_guide.md`。

## 时长规则

- 目标 ≤ 4 分 50 秒，上限 5 分钟。超了按这个顺序删：形近陷阱 → 迁移题 → 按 `order` 从不重要的主词删起（最多删到 4 个）。
- 删掉的内容网页版里都在，被删的词仍显示在家族图上。
- 不靠加快语速来压时长。

## 文件夹结构

```
word-family-video/
├─ SKILL.md                    agent 的工作流程
├─ 使用说明.md                 本文件
├─ assets/frame.html           视频画面模板（版式、出场动画、逐笔画出、字幕）
├─ scripts/video.py            init / plan / stills / render / check
├─ references/narration_guide.md  解说词写法、时长与删减、读音修正
├─ evals/                      行为测试用例
├─ projects/<词根>/            每支视频一个目录：narration.json（进 git）+ 产物（不进 git）
└─ cache/tts/                  配音缓存（不进 git）
```

## 借鉴与出处

- 「先画线稿、后上色」「元素绑定到某一句解说出场」的思路来自 [geeklee/srt-whiteboard-animation](https://github.com/geeklee/srt-whiteboard-animation)（MIT）。它处理的是位图（OpenCV 骨架追踪），我们的线稿本来就是矢量，所以只借了思路，用 SVG 描边动画实现，没有搬代码。
- 「逐句配音、用配音时长排时间线、逐帧确定性渲染」的做法与 [narrated-slide-video-toolchain](https://github.com/alex454-byte/narrated-slide-video-toolchain)（MIT）相同。
- 读音回听检查的思路来自 [explainroo](https://github.com/vincentsch/explainroo)（MIT）。

## 限制

- 配音需要联网（edge-tts 是免费的在线服务）；断网时已缓存的句子仍可用。
- 只有一种画风（米白纸面线稿）和一个声音。
- 画面问题要回 word-family 改课程，视频这边不单独改画面。
