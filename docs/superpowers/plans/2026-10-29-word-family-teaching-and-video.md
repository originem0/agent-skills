## 4. 人物真正参与动作

- [x] 沿用现有 SVG 与 Playwright/ffmpeg 管线，增加视频人物关节绘制与动作，不引入依赖或更换框架。
- [x] 让肘膝、头部、重心和左右肢体体现拉、推、走、递、指等不同动作；用自然曲线和清楚的落点改善僵硬线条。
- [x] 动作有准备、发生和停留，按语音触发或显式配置；背景残影不动，静止时不持续晃动。
- [x] 静帧复核发现搬运目前只在原地屈膝，进出仍靠箭头说明；补明确的起点轨迹、人物与道具同行、交替落脚，支撑梁继续保持原地。参数先记入场景文档，再实现并在实际连续帧中验证。
- [x] 绳子始终连着实际手的位置，脚的落点与道具关系合理；任意顺序调用 setT 仍得到相同姿势。
- [x] 动作期间向逐帧渲染器报告变化，不能因复用旧帧而丢掉身体动作；审查包含动作前、中、后。

主要涉及视频人物资源、frame.html、画面数据与审查采样。共享静态零件与旧 HTML 保持兼容。

## 验收尺度

变化服务于理解，而不是随机打乱事实。一次小结应把新增关系接回主线，不能只重复词表。人物的改善要能在连续帧中看见，不能用多几个静态姿势名或整张图的缩放代替。

本机使用 `skills/word-family-video/.venv/Scripts/python.exe`；继续复用已装依赖。维护范围内遇到失败先分段定位、修复后复测，不把用户已授权的中间审核再交回用户。
